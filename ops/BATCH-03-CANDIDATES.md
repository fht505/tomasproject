## Why these need screening before any art exists

Batch 1 was built in the expensive order — 34 designs drawn, then trademarks
screened. Two finished designs died: "Teach Love Inspire" contained TEACH LOVE
(live, Class 25) and "Spoiling Is My Love Language" contained LOVE LANGUAGE
(registered 2026-05-05, Class 25, actively enforced). Both were *containing*
marks, invisible to an exact-phrase search.

Screening these first costs minutes. Screening them last cost a night.

## Known risks in this specific list

- **"Chaos Coordinator Fuel"** — our own B2/C3 use "Professional Chaos
  Coordinator" and it passed, but CHAOS COORDINATOR is a heavily filed phrase.
  Screen carefully, and check Class 4 (candles) specifically.
- **"Burn After Parenting"** — plays on *Burn After Reading*, a Focus Features
  film. Parody titles are usually fine, but check for a live mark.
- **"Certified Homebody" / "Overthinking Season"** — short, brandable, exactly
  the shape that gets registered. Highest registration risk in the list despite
  low competition.
- Everything else is long and descriptive, which historically screens clean.

## The class that matters

These are **candles: Class 4** (candles/wicks), not Class 25. A mark live for
apparel does not necessarily block a candle — Sweater Weather was rejected
because Reg 4334978 is live in Class 4 *specifically*. Screen against the class
we are actually printing on.
