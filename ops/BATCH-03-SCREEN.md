## The four flagged risks, resolved

- **Chaos Coordinator Fuel — cleared.** The doc was right that the phrase is
  heavily filed and right to ask for Class 4 specifically. Both housewares
  filings (drinkware Cl 21, tumblers Cl 21) are abandoned, and no one has ever
  taken it to candles. B2/C3's existing "Professional Chaos Coordinator" stays
  safe on apparel, and Cl 21 is currently clear too.
- **Burn After Parenting — killed, but not by the film.** Parody of the Focus
  Features title was never the problem. A candle seller registered
  `BURN AFTER READING` for candles and wax melts (Reg 8004133, Oct 2025).
  Same class, same goods, same construction.
- **Certified Homebody — cleared.** The doc's instinct was right that it is
  exactly the shape that gets registered, and HOMEBODY *is* filed constantly.
  But the Class 4 candle attempt died in May 2026 and the Class 3 registration
  was cancelled in 2016. Nothing live touches our goods.
- **Overthinking Season — cleared.** Only eight OVERTHINKING marks exist at
  all, none anywhere near Class 4/3/21.

- **Sweatpants Weather** — no mark contains or is contained. It fails on

## The Etsy shop-name finding

Four phrases have an **exact** shop-name match: `ReheatedCoffeeClub`,
`OverthinkingSeason`, `SundayResetRitual`, `CertifiedHomebody`. All four have
**zero active listings**.

That is materially weaker than the Dog Mama precedent that set this rule.
Measured the same way today, "Dog Mama" returns 13 exact/containing shop names
of which several are *actively trading* — `DogMamaBySydney` (42 active),
`DogMamaClothingCo` (5), `DogMamaCanada` (2). A dormant shop with no listings
is a reserved handle, not a trader, and generates no common-law rights.

So the three otherwise-clean phrases are passed with the collision recorded
rather than failed on it. Sunday Reset Ritual fails on the trademark
accumulation above; its shop-name collision is a contributing factor, not the
cause.

## Method, and what it cannot tell you

Two channels, because neither alone is sound:

1. **Discovery — Justia's full-text mirror of the USPTO register.** USPTO's own
   search app is behind an AWS WAF challenge and its Open Data API needs a key
   this project does not have, so the register cannot be queried directly from
   here. Every candidate phrase was searched, plus the containing sub-phrase(s)
   for each.
2. **Verification — USPTO TSDR `statusview`, per serial.** Justia's result list
   does not show live/dead status, so nothing above is decided on it. Every
   decisive call cites the serial whose TSDR page was read. Raw pages were
   retained.

Two failure modes were caught while building this and are worth recording:

- A search snippet is not evidence. The control case, `LOVE LANGUAGE`
  sn90185577, reads as a live Class 25 apparel mark in every search result and
  is **dead** on TSDR — abandoned May 2022.
- **TSDR answers HTTP 403 under rapid requests.** Read naively, a refusal to
  answer looks identical to "no such mark," and five phrases were one careless
  reading away from a false PASS. The fetcher backs off and reports
  `RATE-LIMITED`, never absence.

**Limits.** Discovery depends on a third-party full-text index, so a mark it
does not surface is a mark this screen did not see; searches were English
literal-element only, covering neither design marks nor foreign equivalents.
Class 4 was screened together with 3 and 21 as instructed — a live mark in
another class (notably Class 25 apparel, where `EMOTIONALLY UNAVAILABLE` is
live) does not appear as a blocker here and would need re-screening before any
of these phrases moves onto a garment. This is a screen, not legal advice.

## Method notes worth keeping

Two findings from the screening session change how this should be done again:

1. **TSDR returns HTTP 403 under rapid requests, and a naive read of that
   response is indistinguishable from "no such mark."** Five phrases were one
   careless reading away from a false PASS. Any future screener must back off
   and report RATE-LIMITED — never absence. This is the same class of bug as
   `art.json`'s "ok" once meaning "file exists" rather than "passed".

2. **Search snippets are not evidence.** The control case: `LOVE LANGUAGE`
   serial 90185577 reads as a live Class 25 apparel mark in every search
   result and is DEAD on TSDR (abandoned May 2022). Discovery via index,
   decision via TSDR — never the reverse.

USPTO's own search is behind an AWS WAF and its API needs a key, so discovery
ran through Justia's full-text mirror. That means coverage depends on a
third-party index and on literal elements only; design marks and unregistered
common-law use are out of scope for this method.
